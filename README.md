# Dilhan / Dev — Personal Portfolio

A responsive personal portfolio built with plain **HTML, CSS, and JavaScript**. No build tools, package installation, or framework required.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in your browser.
3. Optional: use the **Live Server** extension in VS Code for local development.

## Deploy with GitHub Pages
1. Create a new repository on GitHub, for example `dilhan-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site. The URL will look like:
   `https://dilhanmaduwantha5566.github.io/dilhan-portfolio/`

If you name the repository exactly `dilhanmaduwantha5566.github.io`, the URL will instead be:
`https://dilhanmaduwantha5566.github.io/`

## Personalize before publishing
- Replace any content you want to update in `index.html`.
- Confirm your phone number, email, GitHub, and LinkedIn details are correct.
- Add links to individual project repositories when you have them.
- If you add a CV, place the file in this folder and link to it from the page.

## Notes
- The page uses Google Fonts, so the fonts need an internet connection; system fallback fonts are included.
- Project content is phrased as academic experience and planned team functionality, not as a claim that every listed feature is production-ready.
